# فیلم‌بین

یک سایت نمایش اطلاعات فیلم مشابه فیلیمو، ساخته‌شده با Next.js (App Router) و
shadcn/ui که داده‌ها را از [TMDB](https://www.themoviedb.org/) می‌گیرد.
تمام رابط کاربری فارسی و راست‌به‌چپ (RTL) است.

این پروژه فقط **فهرست** فیلم‌ها را نمایش می‌دهد — پخش‌کننده ویدیو یا امکان
تماشای فیلم پیاده‌سازی نشده است. در صفحهٔ جزئیات هر فیلم، لیست ویدیوهای
مرتبط (تریلر/تیزر) نمایش داده می‌شود که با کلیک روی هرکدام، در یوتیوب باز
می‌شود.

## امکانات

- صفحهٔ اصلی: فهرست فیلم‌ها بر اساس ژانر با صفحه‌بندی
- صفحهٔ جزئیات فیلم: پوستر، بک‌دراپ، خلاصه داستان، بازیگران، ژانرها،
  امتیاز، تاریخ اکران (شمسی) و لیست ویدیوها
- فونت فارسی Vazirmatn و چیدمان کامل RTL
- کامپوننت‌های shadcn/ui (Button، Card، Badge، Separator، Skeleton)

## راه‌اندازی

۱. متغیرهای محیطی را تنظیم کنید. فایل `.env.example` را کپی کرده و مقدار
واقعی کلید و توکن TMDB را در `.env.local` قرار دهید:

```bash
cp .env.example .env.local
```

```
TMDB_API_KEY=...
TMDB_API_READ_ACCESS_TOKEN=...
```

توکن دسترسی (v4 Read Access Token) برای احراز هویت درخواست‌ها به صورت
`Authorization: Bearer` استفاده می‌شود. این مقادیر هرگز نباید در مخزن
گیت کامیت شوند.

۲. وابستگی‌ها را نصب و سرور توسعه را اجرا کنید:

```bash
npm install
npm run dev
```

سپس آدرس [http://localhost:3000](http://localhost:3000) را باز کنید.

## ساختار پروژه

- `src/lib/tmdb.ts` — کلاینت TMDB (ژانرها، فهرست فیلم‌ها، جزئیات فیلم)
- `src/app/page.tsx` — صفحهٔ فهرست فیلم‌ها بر اساس ژانر
- `src/app/movie/[id]/page.tsx` — صفحهٔ جزئیات فیلم
- `src/components/` — کامپوننت‌های رابط کاربری

## استقرار (Deploy)

برای اجرا در هر پلتفرمی (مثل Vercel)، حتماً متغیرهای `TMDB_API_KEY` و
`TMDB_API_READ_ACCESS_TOKEN` را در تنظیمات محیطی همان پلتفرم وارد کنید.
